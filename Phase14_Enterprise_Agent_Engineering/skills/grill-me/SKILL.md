# Grill me — enterprise adaptation

This is a modified, provider-neutral adaptation of Matt Pocock's grill-me/grilling skills. Read [UPSTREAM.md](UPSTREAM.md) for provenance and [scenario instructions](references/scenario.md) for the enterprise question areas. The included MIT license applies to the upstream-derived material.

Inspect relevant repository facts first. Build a decision tree from the user's actual proposal and already-settled decisions. Separate facts you can inspect from choices only the user can make.

Ask a manageable round of independent, consequential questions with a recommended answer and tradeoff. Wait for those answers before asking dependent questions. Respect a user-specified time/question limit; do not reopen decisions already settled in the session. Continue independent factual inspection while answers are pending, using available tools; no particular Skill tool or delegated agent is required.

Challenge contradictions and unsupported assumptions with concrete failure examples. Do not turn routine implementation work into an unsolicited interview. When the user asks only for an asynchronous review, report findings and open decisions rather than forcing dialogue.

Conclude with settled decisions, unresolved risks, scope, and testable acceptance criteria. A requested design interview does not itself authorize implementation, deployment, messages, or production actions. Respect any implementation authorization already given; do not add a ritual confirmation after the user has settled the relevant scope.
